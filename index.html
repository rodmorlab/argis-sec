Centro de Operaciones DevOps & Auditoría DevSecOps

Evidencia técnica del pipeline en GitHub Actions, integración de controles SAST/DAST/SCA y comparativa de vulnerabilidades detectadas, corregidas y verificadas.

Flujo Automatizado GitHub Actions (CI/CD + Umbral de Seguridad)

Si una prueba unitaria falla o npm audit / CodeQL detecta una vulnerabilidad de severidad Alta o Crítica, el pipeline bloquea automáticamente el despliegue a producción.

STAGE 1 · PASS 1. Git & Build Checkout rama main, npm ci, compilación y linter.
STAGE 2 · PASS 2. SAST (CodeQL) Análisis estático de código JS/TS sin inyecciones NoSQL.
STAGE 3 · PASS 3. SCA (npm audit / Snyk) 0 vulnerabilidades críticas o altas en paquetes Node.js.
STAGE 4 · PASS 4. DAST (OWASP ZAP) Escaneo dinámico sobre staging: cabeceras Helmet y CSP OK.
STAGE 5 · DEPLOYED 5. Hosting HTTPS Publicación en Render/Vercel con variables de entorno seguras.
